Istruzioni per l'utilizzo del software:

1. Effettuare il fork del progetto sul proprio profilo di github.

2. Importare il progetto nel proprio ambiente di sviluppo.

3. Installare le librerie riportate nel file "requirments.txt".

4. Importare il data-set "nba_travel.sql" dalla cartella database.

5. Dopo aver inserito le proprie credenziali nel file "connector.cnf" eseguire il file "main" del progetto per avviare il programma.
